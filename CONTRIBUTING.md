# Contributing

Contributions are welcome through GitHub Issues and Pull Requests. By submitting a contribution, you confirm that you have the right to provide it and agree that it may be distributed under the repository licence and any future Change License applicable to the relevant release.

1. Read `AGENTS.md` and the referenced product standards.
2. Create or reference an issue for non-trivial work.
3. Use a focused branch and preserve the public/private boundary.
4. Update every affected locale and canonical route.
5. Run `npm run check` and the Wrangler dry-run.
6. Open a Pull Request using the repository template.
