# Documentation language

English is the only durable language for public technical documentation, contribution instructions, user guides, agent guidance and explanatory comments in this active repository.

Direct interaction with the architecture owner may show command comments in English followed by Russian. The Russian presentation is transient and must not be committed, stored in prompts, copied into browser workspaces or retained in generated artefacts.

Managed product localisation is separate from canonical technical documentation.

The authoritative project decision is `claryel-company/claryel-platform` ADR-0034. Archived repositories are outside the active scope and must not be analysed or referenced.
